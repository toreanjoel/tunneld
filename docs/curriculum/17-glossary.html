17 — Glossary

Reference: All curriculum pages, lib/tunneld/*.ex

This glossary defines every term used throughout the curriculum. Terms are grouped by category and listed alphabetically within each group.

Networking

AllowedIPs
In WireGuard, the IP ranges that should be routed through a peer. Packets destined for these addresses go into the tunnel; packets from these addresses are accepted from the peer.
CIDR
Classless Inter-Domain Routing. A notation for IP addresses and subnets, e.g., 10.0.0.0/24 means "the first 24 bits are the network, the rest is the host."
conntrack
Connection tracking. The kernel subsystem that tracks the state of network connections (NEW, ESTABLISHED, RELATED). Used by iptables for stateful firewalling.
DHCP
Dynamic Host Configuration Protocol. Automatically assigns IP addresses and network settings (gateway, DNS) to devices joining a network.
DNS
Domain Name System. Translates human-readable names (google.com) to IP addresses (142.250.80.46). Hierarchical, distributed database.
Downstream
In Tunneld, the network interface facing the local subnet (LAN). Devices connect here and receive DHCP leases from the gateway.
Egress
The exit point for traffic leaving a network. In Tunneld, "egress" refers to routing a device's traffic through a remote machine instead of the gateway's own upstream.
FORWARD
An iptables chain for packets being routed through the machine (not destined for it or originating from it). Controls what traffic can transit the gateway.
INPUT
An iptables chain for packets destined for the local machine. Controls what traffic can reach services running on the gateway.
ip rule
A policy routing rule that selects which routing table to use based on packet characteristics (source IP, incoming interface, etc.).
iptables
The Linux firewall and packet manipulation tool. Interface to the Netfilter kernel subsystem. Organizes rules into tables, chains, and targets.
MASQUERADE
An iptables target that rewrites the source IP of outgoing packets to the outgoing interface's IP. Used for NAT when the IP is dynamic.
NAT
Network Address Translation. Rewrites IP addresses in packet headers, typically to allow private-address devices to reach the public internet through a gateway.
Overlay
A virtual network layered on top of physical networks. In Tunneld, the WireGuard overlay gives remote machines local-like addresses (10.88.0.x).
PersistentKeepalive
WireGuard option that sends keepalive packets every N seconds. Keeps NAT mappings alive and ensures the tunnel stays connected.
Policy Routing
Routing based on criteria beyond destination address: source IP, incoming interface, packet marking. Implemented via ip rule and multiple routing tables.
Port
A 16-bit number (0-65535) identifying a service on a machine. Combined with IP address to form a socket address.
Reverse Proxy
A server that receives client requests and forwards them to backend servers. Provides load balancing, SSL termination, and hostname-based routing.
Routing Table
A data structure that maps destination networks to next-hop addresses and interfaces. Linux supports multiple tables for policy routing.
Socket
An endpoint for network communication: the combination of IP address + port that a process binds to or connects to.
Subnet
A logical division of an IP network. Defined by a network address and prefix length (e.g., 10.0.0.0/24).
Table=off
WireGuard/wg-quick option that prevents automatic route installation. Routes must be added manually. Required for Tunneld's policy routing.
Upstream
In Tunneld, the network interface facing the internet. Traffic exits the gateway through this interface (unless egressed through a remote machine).
WireGuard
A modern VPN protocol built into the Linux kernel. Uses public-key cryptography for identity, minimal configuration, and high performance.

Elixir/OTP

Assign
In LiveView, storing a value in the socket's assigns map. Changes to assigns trigger re-renders.
BEAM
The virtual machine that runs Erlang and Elixir code. Provides lightweight processes, garbage collection, and distribution.
GenServer
A generic server behavior. A process that handles synchronous calls, asynchronous casts, and info messages while maintaining state.
handle_event
LiveView callback for user interactions (clicks, form submissions). Receives the event name, params, and socket; returns the updated socket.
handle_info
GenServer/LiveView callback for arbitrary messages (PubSub broadcasts, timers). Not initiated by a call/cast.
LiveView
Phoenix framework for building real-time web interfaces. Server renders HTML, sends diffs over WebSocket, handles events on the server.
Mount
LiveView lifecycle phase. Called on initial HTTP GET and WebSocket connect. Sets up initial state and subscriptions.
OTP
Open Telecom Platform. Libraries and design principles for building concurrent, fault-tolerant applications. Includes GenServer, Supervisor, Application.
Process
A lightweight, isolated unit of execution on the BEAM. Has its own heap and mailbox. Millions can run concurrently.
PubSub
Publish-subscribe messaging. Processes subscribe to topics and receive messages when anyone broadcasts to that topic.
Release
A self-contained package of an Elixir application and the Erlang runtime. Deployable without installing Elixir on the target.
Supervision Tree
Hierarchical structure of supervisor and worker processes. Supervisors restart crashed children according to a strategy.

Tunneld-Specific

address_for/1
Function in lib/tunneld/overlay.ex that returns the reachable IP for a machine: LAN IP if local, overlay IP if remote.
Device
In Tunneld, a machine that received a DHCP lease from the gateway. Visible in the dashboard with MAC, IP, and hostname.
Listener
A process bound to a socket. Discovered via ss -tlnp. Any listener can be promoted to a resource.
Machine
A Linux host enrolled in Tunneld with SSH access. Can be local (on the subnet) or remote (reachable via WireGuard overlay).
Mock Mode
Development mode where system commands are stubbed and fake data is returned. Allows running Tunneld on macOS without real hardware.
Pool
A list of backend addresses for a resource. Caddy load-balances across pool members.
Resource
A named pointer to one or more backends. Reachable at <name>.tunneld.lan:18000 and via a loopback port.
tunneld.lan
The local domain resolved by dnsmasq. All *.tunneld.lan names resolve to the gateway IP.

System Administration

dnsmasq
Lightweight DNS forwarder and DHCP server. Used by Tunneld for local name resolution and IP assignment.
journalctl
Command to view systemd journal logs. journalctl -u tunneld shows Tunneld's logs.
SBC
Single-Board Computer. A complete computer on one circuit board (Raspberry Pi, NanoPi). Tunneld's target deployment platform.
SSH
Secure Shell. Protocol for encrypted remote access. Tunneld uses SSH to run commands on managed machines.
systemd
The init system and service manager for modern Linux. Manages service startup, dependencies, and logging.
wg-quick
Helper script for WireGuard. Reads /etc/wireguard/*.conf and sets up interfaces, addresses, and routes.
