Tunneld Learning Curriculum

▶ Present as slides → moves between sections, ↓ moves through one. Esc for the overview.

This curriculum teaches you how Tunneld works from the ground up. It is designed for the project author to learn and re-learn the system and every subsystem it touches. Each page teaches the underlying technology from first principles, then shows exactly how Tunneld uses it, with real code citations and runnable examples.

How to Use This Curriculum

Work through the pages in order. The first two pages establish the mental model; pages 02-16 and 18 teach each subsystem in depth. The glossary (page 17) defines every term used throughout. Each subsystem page answers five questions:

  • What it is — the technology explained in plain terms
  • How it works — the actual mechanism: handshakes, syscalls, packet flow
  • How Tunneld uses it — the exact way this codebase applies it
  • Why — why this choice over alternatives, honest tradeoffs
  • Examples — real, runnable commands with worked-through output

Learning Path

00
Orientation
What Tunneld is, the problem it solves, and the mental model: "a resource is an address, not a container."
01
Architecture
Full architecture, module map, supervision tree, request lifecycle, data flow from browser click to SSH command.
02
Networking Foundations
IP addresses, subnets/CIDR, routing, NAT, ports, sockets, TCP listen, LAN vs overlay addresses.
03
WireGuard
Crypto-routing, keypairs, AllowedIPs, handshakes, PersistentKeepalive, NAT traversal, Table=off.
04
iptables & NAT
Netfilter, tables/chains/targets, FORWARD vs INPUT, MASQUERADE, conntrack, the built-in chains tunneld writes to.
05
Routing Tables & Egress
Policy routing, ip rule, multiple routing tables, per-device exit selection, DNS leaks.
06
Caddy Reverse Proxy
Reverse proxies, Host-header routing, the JSON admin API, automatic HTTPS/ACME, why Caddy over nginx.
07
DNS, dnsmasq & DHCP
DNS resolution, records, dnsmasq as resolver+DHCP server, DHCP DORA handshake, option 3, .lan domains.
08
SSH Transport
SSH protocol, keypairs, authorized_keys, ControlMaster multiplexing, non-interactive exec.
09
Elixir & OTP Supervision
BEAM, processes, GenServer, supervision trees, let-it-crash, when a GenServer is right.
10
Phoenix LiveView
LiveView lifecycle, mount/render/handle_event, diffs over websocket, PubSub, components, hooks.
11
Persistence & State
JSON-on-disk state, atomic write + backup, "remote state is authoritative," idempotence and reconciliation.
12
Agent API & Auth
Bearer tokens, hashing at rest, scopes, audit logging, the jobs pattern for long operations.
13
Build, Release & Deploy
Mix releases, ERTS bundling, glibc compatibility, the build_release.sh Docker builder, the stale-beam hazard.
14
Testing & Mock Mode
ExUnit, mock mode (MOCK_DATA), what is and is not covered, what makes a test worth keeping.
15
systemd Service Lifecycle
Units, service types, enable vs start, journald, restart policy, how tunneld and wg-quick are managed.
16
Pooling & Load Balancing
Backend pools, health checks, load-balancing policies, mixing local devices and remote VMs in one pool.
17
Glossary
Every term used anywhere in the curriculum, defined.
18
Terminal Exec
Interactive SSH terminals via Phoenix channels, xterm.js, and Erlang :ssh. Three bugs found in production.

Source of Truth

This curriculum is derived from reading the actual code. Key modules include:

  • lib/tunneld/overlay.ex — WireGuard peering
  • lib/tunneld/egress.ex — policy routing for per-device exits
  • lib/tunneld/iptables.ex — firewall rule management
  • lib/tunneld/caddy.ex — reverse proxy configuration
  • lib/tunneld/machines/ssh.ex — SSH transport
  • lib/tunneld/machines/runtime.ex — listener discovery
  • lib/tunneld/reconcile.ex — drift detection
  • lib/tunneld/persistence.ex — atomic JSON writes
  • lib/tunneld/agent_tokens.ex — bearer token auth
  • lib/tunneld/application.ex — supervision tree
